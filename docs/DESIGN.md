# 视觉规范

面向改站点页面时的一次性参考：先照这套 token 做，再考虑破例。实现都在 `public/styles.css` 的 `:root` 里。

## 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#16231f` | 正文、标题、条目页分隔粗线 |
| `--ink-2` | `#4d605a` | 次要文字、榜号、未选中菜单 |
| `--ink-3` | `#576561` | 时间、度量、说明性小字（与纸面对比 5.4:1） |
| `--paper` / `--paper-2` | `#eef1ec` / `#e5eae4` | 页面底色 / 面板底色（冷调，不用奶油米色） |
| `--pine` / `--pine-deep` | `#0e5c48` / `#0a4437` | 结构色：报头、链接、深度量条、按钮 |
| `--signal` | `#d99a21` | 只给「实用」量条、报头底边、当前栏目下划线 |
| `--signal-ink` | `#6b4a05` | 信号黄上的文字 |
| `--warn` | `#8f4a2f` | 只用于「抓取失败」这类故障提示 |

整站只有两种强调色，用法固定：**松绿 = 结构，信号黄 = 可实操**。黄色不再用于装饰。

## 字体

- 标题、榜号、漏斗数字、条目页正文：`--serif`（Songti SC / Source Han Serif / Noto Serif CJK / Georgia 回退），`font-variant-numeric: lining-nums tabular-nums`。
- 界面与摘要：`--sans`（PingFang SC / Microsoft YaHei 系）。
- 字号阶：漏斗数字 44（窄屏 34）→ 页面 h1 28–30 → 头名标题 26 → 条目标题 19 → 正文 15.5 → 次要 13。
- 正文行长 ≤ 74ch；衬线正文行高 1.9，无衬线 1.75–1.85。

## 版式

- 单栏、左对齐。列表宽度 960px，阅读类内容（条目页、关于、讨论）限制在 740px。
- 条目列表是三列栅格：榜号轨（30px） / 正文 / 缩略图轨（116px，头名 168px）。窄屏缩略图移到正文下方。
- 报头是整幅松绿色带，底边 3px 信号黄；菜单贴在报头下方，当前栏目用 2px 信号黄下划线表示，不用胶囊。

## 质量闸门作为视觉语法

每条的深度与实用都用 `.meter` 量条表示：数字 + 54px 刻度，刻度里的竖线（`--gate-at`）就是 `config/filters.json` 的质量闸门。条超过竖线才算过关，所以读者能看出「这条离门槛多远」。

## 写作

- 主动语态，按钮说清会发生什么：「发布留言」「订阅 RSS」。
- 链接文字不加 `→`、`↗`；`→` 只用于漏斗里「抓取 → 入选」这类真实数据流向。
- 次要信息写成短句，不用 `A · B · C` 串联；不用全大写眉标。
- 空状态和失败状态给下一步，不给情绪：「这一栏最近没有新内容，换个栏目看看。」

## 动效

只有一处：漏斗读数一次性数到位（`public/funnel.js`）。`prefers-reduced-motion: reduce` 时直接显示终值，全站禁用动画。加新动效前先确认它回答读者的某个动作。
