机器人越造越多，真正能“上岗“的却不多。据《2026年人形机器人产业发展报告》，今年上半年我国人形机器人出货量已超4万台；而一线调研显示，超六成的具身智能项目仍停留在验证或演示阶段，真正进产线连续、稳定作业的只是少数企业。
“这一现象背后是机器人部署成本高、换产难、长期稳定性不足等难题”。在近日举行的 2026北京ACE科技创新大会上，XROGO CEO郑随兵指出，机器人能否持续在真实场景作业，正成为其关键价值所在。他表示“机器人终究是一种劳动力，不能只停留在视频里，必须走进真实场景把活干好、干久。” 在郑随兵看来，当前行业真正缺的不是更多机器人，而是把活儿稳定干完的作业能力。机器人的价值也并非去替代传统自动化已能做好的事，而是把人的经验、技能真正复刻出来。
行业缺的不只是机器人，而是“买得起、用得好”的劳动力
当前，制造业、电力、物流等行业普遍招工难、留人难。不少岗位环境艰苦：高噪音、高温高湿、油污粉尘，要熬严寒酷暑、上夜班、重复取放，企业常年贴着招工启事，但很难招到人；配电室、变电站需要持证电工全天值守，冷库、矿井、电线维护的工作时刻都暗藏风险；磨床操作、工件修型、火工品刮研这类活，高度依赖老师傅的经验，人一走工艺就断档。
不仅如此，不同地域还存在巨大的成本落差。同样的岗位，不同区域时薪差距悬殊，欠发达地区经济体员工时薪显著低于发达经济体。一边是“人不愿来、留不住”，一边是“成本压不下去”，这构成了机器人最真实的应用理由。
有需求存在但不等于能被满足。郑随兵指出，传统工业自动化高度依赖集成部署，“占地大、投入高，换一种工件，产线就要大改”，结果往往是“买了设备用不起来”。机器人“部署”进了工厂，却没有真正“上岗”，这也解释了行业为何一边刷新出货量新高，一边在真实作业上进展迟缓。
作为聚焦建设全球劳动力基础设施，打造全球劳动力调用与作业平台的企业，XROGO第一步就是把机器人上岗门槛降下来，在真实场景里“用得好”。在常州超级工厂等真实场景里，机器人已在分料、拣选、推送和磨床操作等环节实现了100多个岗位的”真上岗“。操作一台机床，插电、联网到远程部署约4分钟，到岗计划最快3小时。
郑随兵着重指出，“我们没必要等到具身智能达到100%完美，通过远程协同和遥操兜底的方案也能让机器人先作业起来。”一线工人不用写任何代码可用自然语言告诉机器人该做什么，并能通过远程遥操的方式“干活”，这一过程本身就是机器人学习的过程，实现人不在现场，也能了解注意事项、提前规避异常。机器人不再是焊死在产线上的固定设备，而是能快速到岗、迅速切换任务、由一线人员带教的“新劳动力”。

我让 Agent 长出了眼睛和耳朵。起因是腾讯开源的全模态视频理解模型 WeMM-Video（Apache-2.0，2B / 4B / 9B / 35B-A3B 四档）：喂一个视频文件进去，模型同时看画面、听原声，输出描述或逐字转写。我在M5 Ultra 256GB 机器上把它完整跑通并做了三档横向测试，最终定档 35B-A3B。我要先讲它对我意味着什么，再讲怎么跑通、为什么选 35B。
一、长出眼睛和耳朵：能力的一次分水岭
把最近折腾过的所有东西排一遍，这是对我个人最重磅、含金量最高的功能性补全，没有之一。视频理解在行业里不是新词，但在我地机器上，Agent 一直缺一件趁手、不联网、画面和声音一起吃得下的工具。WeMM-Video 跑通补的就是这一件，我能看的它都能看、我能听的它都能听，全程本地。这不是把某件事做得更快，是"做不了"变成"能做"，我的工作流里从此多了一个感官通道。
1. 从发现到装上：打动我的是综合能力和好用两样都占了
要说"看得懂视频"这个能力并不稀缺：云端有 Gemini 这类原生吃音视频的旗舰；开源阵营里 Qwen2.5-Omni / Qwen3-Omni、MiniCPM-o、VideoLLaMA 系列、video-SALMONN 都在做音视频联合理解，还有专门的长音视频评测基准在推进。这些名字我听过，但一直没动手——因为此前的每一条路，都差着最后一口气：
云端多模态 API ——能力最强，但内容出网。教程资讯无所谓，敏感素材直接出局；而且依赖网络和外厂配额，流水线里多一个不受控的环节。
开源自建，生态重心在 CUDA ——上面那批开源 omni 模型，官方量化与运行时主要面向 NVIDIA。MAC上并非完全没有路：mlx-vlm 这类框架已经收录了 Qwen3-Omni、MiniCPM-o 的社区 MLX 移植，HF 上也有若干 omni 模型的社区量化版。但这些移植多为个人维护、跟进上游有滞后，视频 + 音频联合输入的实际质量与速度少有系统实测；官方代码路线则走 torch/MPS 回退——同机我们实测的 torch 回退速度只有 3–4 tok/s（WeMM-9B，稠密模型，其他同量级 omni 大概率同档，此为推断非实测）。能用，但离"趁手"有距离。
VLM + Whisper 两段拼接 ——社区最常见的本地土办法：抽帧给视觉模型、音轨给 Whisper。能用，但画面和声音是两个模型各看各的，"谁在什么时候说了什么、对着哪个画面"这层联合理解没有，跨模态的时序对应靠事后拼，错误在拼接处滋生。
