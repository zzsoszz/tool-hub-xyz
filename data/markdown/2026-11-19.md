近日，全球首个医疗健康 AI 独立评测与分析平台InclusionMed 正式上线，并同步推出医疗 AI 评测图谱 InclusionMed Atlas 和首期医疗 AI 评测指数 InclusionMed Index，旨在为医疗健康 AI 提供更加系统的评估依据。该平台由来自斯坦福大学、哈佛大学、北京协和医学院、蚂蚁集团、InclusionMed.AI等29家机构的研究人员共同建设，被视作医疗健康领域的Artificial Analysis（AA），填补了全球医疗健康 AI 综合测评的空白。
一个在健康问答中表现出色的 AI，能否同样做好复杂的专业医疗任务？如何识别疑难病例中的关键线索、在电子病历系统中准确完成操作、处理医学研究与医疗运营中的多步骤任务？每一种场景，都对模型提出了不同要求。针对具体医疗任务下的模型能力，业内已有多种评测基准，但单项测试成绩难以完整反映模型在不同医疗任务中的表现。
据了解，InclusionMed Atlas 围绕“面向谁”和“考察什么能力”两个维度，将患者与公众、医疗专业人员、医疗管理人员三类角色，与知识、推理、任务执行三类能力交叉，形成九宫格评测图谱。每项基准按其主要评测内容归入相应位置，帮助使用者看清当前评测覆盖了哪些医疗需求、哪些方面仍需补充。InclusionMed Index 则汇集纳入基准的评测结果，呈现模型的综合表现及其在不同任务中的优势与不足。
首期评测聚焦临床诊疗与医疗管理两大方向，纳入五项评测基准、1034项任务，对国内外11家厂商的22个模型进行系统比较，并经过独立复测，综合考察医疗相关性、评测可信度、场景互补性等因素，最终选出四项公开评测基准，与团队自建的 InclusionMed-DxFiles 共同构成首期指数。其中，InclusionMed-DxFiles 基于顶级医学期刊刊载的疑难病例构建，考察模型结合病例线索进行临床判断的能力。

以前用手机拍摄的家庭录像、分辨率只有 480P 或 720P 的老视频、从网上下载的压缩视频，以及 AI 生成的短片，常常存在 画面模糊 、 细节不足 或 噪点较多 的问题。直接将这些视频放大到1080P或4K，虽然分辨率提高了，但原本缺失的细节并不会自动恢复，有时画面反而会显得更加模糊。
有没有办法在放大视频的同时改善画面质量？
这就涉及到 AI 视频超分辨率（AI Video Super Resolution） 。与普通放大不同，AI超分可以通过模型分析画面内容，尝试重建纹理、改善边缘和减少噪点，让低分辨率视频获得更好的观看效果。

SSH Key 是远程连接 Linux 服务器、管理 NAS 等设备时常用的身份验证方式，可以不用输入密码登录服务器。很多安全规范都要求服务器取消密码登录，改为使用 SSH Key 登录，降低密码泄露、暴力破解和撞库带来的风险。
但 SSH 私钥本身就是一个普通的文件，它就放在那里（比如 ~/.ssh/ 下），如何没有设置密码，当前用户运行的程序都可以读取它，甚至直接拿走。
那么，有没有办法让 SSH 私钥无法被复制？
现代的 Mac 和 Windows 电脑都可以利用安全硬件保护 SSH 私钥：
Mac：Secure Enclave（安全隔区） 。将 SSH 私钥保存在 Mac 自带的安全硬件中，私钥无法导出，使用时还可以通过 Touch ID 授权。
Windows：TPM 2.0 安全芯片 。借助第三方工具，在 TPM 中生成不可导出的 SSH 私钥，还可以配合 Windows Hello 进行身份验证。
这样，即使运行了各路 AI 撰写的不靠谱的程序，也无法读取私钥。

利用这一功能，可以直接在 Secure Enclave 中生成 SSH 私钥，并且：
私钥无法导出 ：即使有人复制了整个硬盘，也拿不到私钥。
支持 Touch ID ：连接服务器时，可以要求指纹验证。
无需保存传统私钥文件 ：实际签名操作由安全硬件完成。
这意味着，即使 Mac 上的普通文件被恶意程序窃取，攻击者也无法直接复制这把 SSH 私钥，在其他电脑上使用。
