新人首貼，分享一個最近搓出來的小工具。
起因
DSH 內建的 web_search 走官方搜尋 API。我機器上本來就裝了 ego-browser（ego lite）——一個人和 agent 共用的瀏覽器，agent 能用我真實的登入態。某天想到：既然瀏覽器就在本機，何不讓 agent 自己開 Google 搜？不用申請 API key、不用搜尋訂閱，查詢只在自己瀏覽器裡跑，不經過第三方搜尋服務。
於是寫了這個 provider：接上 DSH 的搜尋介面，把預設搜尋換成「ego-browser 開 Google」，順手開源。
效果
裝好之後，下一次 web_search 就走這條路。每次搜尋的完整過程：
開一個獨立 task space → 載入 Google 結果頁 → 抽取有機結果（標題、連結、摘要、發布日期）→ 關閉 space 和所有分頁 → 把結果回傳給 agent。
實測體感：
一次搜尋約 2 秒。結果乾淨：標題＋連結＋摘要＋日期，「3 天前」這種相對日期也會換算成實際日期。
agent 一次丟多個查詢時，內部限流最多開 2 個瀏覽器，其餘排隊，不會一口氣炸出十個分頁。
搜完不留分頁、不留暫存檔，不弄髒你的瀏覽器。
官方搜尋 provider 保留，設定頁隨時切回；這個插件只改預設。
零依賴、零安裝腳本，純 JS，裝完即用。
幾個老實的限制
只有有機連結，沒有官方那種 AI 摘要；比 API 慢幾秒；摘要抽取跟著 Google 目前的版面，大改版可能退化；查太頻繁可能觸發 CAPTCHA，手動過一次再重試就好。
