新人首貼，分享一個最近搓出來的小工具。
起因
DSH 內建的 web_search 走官方搜尋 API。我機器上本來就裝了 ego-browser（ego lite）——一個人和 agent 共用的瀏覽器，agent 能用我真實的登入態。某天想到：既然瀏覽器就在本機，何不讓 agent 自己開 Google 搜？不用申請 API key、不用搜尋訂閱，查詢只在自己瀏覽器裡跑，不經過第三方搜尋服務。
於是寫了這個 provider：接上 DSH 的搜尋介面，把預設搜尋換成「ego-browser 開 Google」，順手開源。
效果
裝好之後，下一次 web_search 就走這條路。每次搜尋的完整過程：
開一個獨立 task space → 載入 Google 結果頁 → 抽取有機結果（標題、連結、摘要、發布日期）→ 關閉 space 和所有分頁 → 把結果回傳給 agent。
實測體感：
一次搜尋約 2 秒。結果乾淨：標題＋連結＋摘要＋日期，「3 天前」這種相對日期也會換算成實際日期。
agent 一次丟多個查詢時，內部限流最多開 2 個瀏覽器，其餘排隊，不會一口氣炸出十個分頁。
搜完不留分頁、不留暫存檔，不弄髒你的瀏覽器。
官方搜尋 provider 保留，設定頁隨時切回；這個插件只改預設。
零依賴、零安裝腳本，純 JS，裝完即用。
幾個老實的限制
只有有機連結，沒有官方那種 AI 摘要；比 API 慢幾秒；摘要抽取跟著 Google 目前的版面，大改版可能退化；查太頻繁可能觸發 CAPTCHA，手動過一次再重試就好。

GitHub（MIT，含繁中 README）： https://github.com/liedwardtw/search-api

《GTA 6》还没登陆 PC，已经有人开始研究，如何让 Xbox Series 版本直接在 Windows 电脑上运行。
此前《 赛尔代传说·时之笛 》的开发者最近放出了一个名为 Leonida 的开源项目，继续通过「静态重编译」技术，将 Xbox Series 版《 GTA 6 》转换成可以在 Windows 上原生运行的程序。
不过注意：这是一个非常早期的技术项目，目前还无法启动游戏，更不能正常游玩。
不用模拟器，直接运行 Xbox 游戏？
Leonida 采用的技术叫做 Static Recompilation（静态重编译），与能在 PC 上玩的塞尔达传说： 时之笛 、 王国之泪 类似。
按照项目的设计，Xbox Series 和现代 PC 都使用 x86-64 架构，因此项目计划在 PC 上直接加载并执行游戏的 CPU 代码，同时重新实现游戏所需的 Xbox 系统接口。
当然，事情远没有这么简单。
除了 CPU 代码，开发者还需要处理 Xbox 系统调用、内存管理、图形接口、音频以及大量游戏运行时依赖。
其中一个难点，就是把 Xbox 使用的 GPU Shader（着色器）转换为 PC 图形接口能够理解的格式。
已经转换了 2.6 万个 Shader（着色器）
根据项目 README， Leonida 已经完成了一些基础工作，包括：
识别 Xbox 游戏文件格式。
转换 26,503 个 GPU Shader，并通过 SPIR-V 静态验证。
已能导出模型、纹理和音频等资源，部分格式仍待处理。
开始开发 Xbox 系统接口兼容层。
开始研究 D3D12 到 Vulkan 的图形转换。
目前，加载器可以运行一个替代测试程序，但游戏本身的可执行文件还未完成测试，也没有展示真正进入《GTA 6》的游戏画面。
说起来，可以算画了个饼，但真有进展。
现在能玩吗？
不能。
截至目前，Leonida 仍处于早期开发阶段，没有可以正常游玩的版本，也没有明确的完成时间。
另外，项目本身不提供《GTA 6》游戏文件，对于普通玩家来说，现在还不需要下载折腾。
但如果你对游戏移植、主机模拟器或者静态重编译技术感兴趣，这个项目值得关注。
毕竟，《GTA 6》的官方 PC 版还没来，开源社区已经开始研究如何让主机版跑在电脑上了。

Strata 0.2.18 于北京时间 11 月 22 日发布，桌面版与命令行版本均升级到 0.2.18，推理引擎和负责安装更新的 Control 升级到 0.1.64。
主要更新：
原生支持 Hy4-Flash 。新增独立的 strata-hy4 推理引擎，选择 Hy4-Flash 量化包时会按需下载。
三档量化 。SQ-64、SQ-96、SQ-128 分别面向不同的内存配置。
内置 DFly2 推测解码 ，用于加快生成。桌面版与 strata launch 都支持。
图像理解 。可加载单独的 Vision 组件，文件大小为 0.93 GB。
跨平台运行 。支持 Windows、Linux、搭载 Apple 芯片的 Mac 以及 DGX Spark。可用的显卡后端因系统而异。
升级后，原有的 Qwen、DeepSeek 模型以及聊天记录和设置都会保留。

Hy4-Flash 与 Qwen3.8-Flash-Next 有什么区别？
两款模型都采用 MoE（混合专家）架构。模型拥有大量参数，每次生成一个 Token 时只调用其中一部分参与计算。Hy4-Flash 的总参数含约 64B Engram 查找参数，每个 Token 激活约 12B 参数。
Hy4-Flash 支持百万级上下文，腾讯将它用于 Agent、文档处理和电脑操作。Qwen3.8-Flash-Next 在 Strata 里已有多种适合消费级硬件的低比特量化方案。
